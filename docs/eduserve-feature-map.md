# EduServe feature map

Public reconnaissance verified the EduServe login landing page at `https://eduserve.karunya.edu/Login.aspx`. It offers KITS Student and Staff/Other role selection, and public text directs password-reset/support queries to Karunya support. Public Karunya material identifies Eduserve as a portal handling academic and administrative matters; a historical university report names exam timetable, online fees, attendance report, IA report, leave, subject registration, HR/MIS, and student reports. These are not proof that every current student account exposes every feature.

| Feature | Evidence | Authentication | Status |
|---|---|---|---|
| Student login | Public login landing page | Required | VERIFIED |
| Password reset | Public student reset page requests register number, DOB, official email | Required flow | VERIFIED |
| Fee receipt | Public payment result page states students/parents can download e-receipts from portal | Required | VERIFIED |
| Attendance, IA, exam timetable, subject registration, leave | Historical university report | UNKNOWN | UNVERIFIED CURRENT AVAILABILITY |

No student credentials were entered and no authenticated data was accessed.
